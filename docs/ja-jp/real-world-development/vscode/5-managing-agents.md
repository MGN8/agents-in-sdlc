GitHub Copilot を Agent モードにすると、コードベースを調べ、変更を提案してファイルを編集し、コマンドを実行します。VS Code の Copilot Chat では、ツールの呼び出しやファイルの編集をリアルタイムで確認できます。差分を個別にレビューして変更を採用または取り消し、エディターを離れずに追加のプロンプトを送って作業を調整できます。

この演習では、次の作業を行います。

- アクセシビリティエージェントの作業をリアルタイムで監視する。
- 提案されたファイルの編集をレビューして採用する。
- セッション中にエージェントへ指示し、高コントラストモードとあわせてライトモードのトグルを追加する。

## シナリオ

[演習 4][previous-lesson]で使ったアクセシビリティ用カスタムエージェントは、高コントラストモードを実装しています。作業中にデザインチームから追加の要望がありました。既定のテーマが暗すぎると感じるユーザー向けに、ライトモードのトグルも追加します。新しい会話を始める代わりに、現在のセッションに指示を追加します。

## Copilot の進捗を監視する

Copilot Chat ビューでは、エージェントが調べたファイル、実行したコマンド、提案した編集を確認できます。ファイルの編集は差分と **Keep** / **Undo** のコントロールとともにチャット内に表示されます。

1. 演習 4 で使った Copilot Chat ビューに戻ります。
2. エージェントの作業中にチャットをスクロールし、ツールの呼び出しを確認します。ファイルの読み取りや編集、実行を求められたターミナルコマンドが表示されます。
3. エージェントがファイルの編集を提案すると、差分がチャット内に表示されます。
   - **Keep** を選択して変更を採用します。
   - **Undo** を選択して変更を取り消し、エージェントに再度作業させます。
4. チャットの上部にある **Files changed** を開き、セッション中にエージェントが変更したファイルの一覧を確認します。

> [!NOTE]
> ターミナルコマンドなどで許可を求める場合、エージェントは一時停止し **Allow** を表示します。内容を確認し、許可してもよいコマンドだけを承認してください。

5. エージェントが高コントラストモードの実装を終えるまで待ちます。最後に、変更内容の概要が表示されます。

## ライトモードを追加するようエージェントに指示する

高コントラストモードを追加したら、同じ会話でライトモードのトグルも作成します。現在のチャットセッションを続けることで、エージェントは変更済みのコンポーネント、スタイルの方針、local storage の使い方などを引き続き参照できます。

1. Copilot Chat に次の追加プロンプトを送信します。

   ```plaintext
   Nice work! Now add a light-mode toggle alongside the high-contrast toggle. Light mode should follow the same pattern — persist via local storage and be accessible from the same area of the UI. The user should be able to enable high-contrast and light mode independently.
   ```

2. エージェントは変更を調べ、ライトモードの追加を提案します。
3. 高コントラストモードと同じように、新しい編集を確認して **Keep** または **Undo** を選択します。
4. 望まない変更を提案した場合は、チャット入力欄の横にある **Stop** を選択して停止し、追加の説明を送ります。

> [!TIP]
> 作業中のセッションに指示を追加すると、最初からやり直すより早く修正できます。「CSS を簡素化して、セレクターの重複ではなく CSS 変数を使う」「3つ目のトグルを追加せず、既存の設定パネルにライトモードを組み込む」「両方のトグルにキーボードショートカットも追加する」など、追加のプロンプトで修正や拡張を依頼できます。

## 作業セットをレビューする

変更をコミットする前に、エージェントが編集したファイルを確認します。

1. VS Code で **Source Control** ビューを開きます。
2. 変更されたファイルの一覧を確認します。Astro コンポーネント、スタイル、関連テストなどが含まれるはずです。
3. いくつかのファイルを開き、差分を確認します。ARIA 属性、キーボード操作、セマンティック HTML、local storage を使った設定の保持など、アクセシビリティのプラクティスが反映されていることを確認します。
4. 内容に問題がなければ、Source Control パネルで変更をステージしてコミットします。次のレッスンで公開します。

## まとめと次のステップ

Copilot Chat の Agent モードでセッションの進捗を監視し、ファイル編集を確認して採用または取り消し、コンテキストを保ったまま追加のプロンプトを送って作業を拡張しました。

この演習では、次の作業を行いました。

- エージェントの作業をリアルタイムで監視した。
- 個々のファイル編集を採用または取り消した。
- セッション中に追加のプロンプトを送り、エージェントの作業を調整した。
